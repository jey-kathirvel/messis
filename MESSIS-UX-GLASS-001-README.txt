MESSIS-UX-GLASS-001 — Application-wide Garden Glassmorphism Theme

Adds a reusable garden-inspired visual system across the complete Messis AI
application. The theme is loaded by the base app, agricultural dashboard and
standalone mobile shell entry points. It styles backgrounds, glass surfaces,
navigation, sidebars, forms, tables, buttons, status elements and mobile UI.

Includes reduced-motion and reduced-transparency accessibility fallbacks.
